# Keira — Portfolio

A lightweight static portfolio for GitHub Pages.

## Pages

- `index.html` — Home
- `about.html` — About
- `projects.html` — Projects
- `contact.html` — Contact

Shared styles are in `styles.css`. Update the example contact email in
`contact.html` before publishing. The pages can be served directly by GitHub
Pages; no build step or dependencies are required.

To personalize the look, adjust the color variables at the top of `styles.css`
and update the copy in the HTML pages. The project books on `projects.html`
open to editable project descriptions.
